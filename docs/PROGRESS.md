## 交付流程

文档和脱敏证据随源码提交；GitHub CI 通过后构建带精确提交的软件包，以独立标签和预发布交付，再安装该发布包做部署烟测。增强版保持核心功能启用，原生进度预览关闭。具体发布提交、CI、校验值及最后部署结果以 Release 的 provenance.json、SHA256SUMS 和 deployment-verification.json 为准。

## 接口边界与维护

只使用 OpenClaw 2026.9.1 的第三方公开 SDK 和 Telegram Bot API。不修改核心文件，不替换内部方法，不新增接收端。保留现有模型、登录、记忆、搜索、浏览器和原生 steer 配置。

停止按钮需要原子任务约束，但公开 submitText 不提供该约束，因此不开放；额外中文停止映射没有可靠公开改写入口，也不增加。补充只确认收到，不推断已采纳。压缩或子任务没有明确关联时跳过，保留原生交付。

重启只收尾遗留状态，不恢复旧任务。新 OpenClaw 版本需要重新验证后再声明兼容。详细结果见 docs/TEST-REPORT.md、docs/FEATURES.md、docs/PUBLISHING.md。
