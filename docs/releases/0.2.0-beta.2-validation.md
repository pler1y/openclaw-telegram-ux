# 0.2.0-beta.2 发布与验证

日期：2026-09-20。兼容范围保持 OpenClaw 2026.9.1。本版发布先前已在主线完成的模块整理、中英文文档、安装示例及文档自动检查；任务处理逻辑保持 beta.1 的行为，显示版本更新为 beta.2。

发布检查包括文档链接、类型检查、87 项自动化、干净构建、包内容与来源提交检查，以及隔离安装、升级、回滚、禁用和卸载。精确源码提交、校验值、实际 CI 和安装检查结果随本版 GitHub Release 发布。

## 实机证据边界

20 个核心场景及具体进度、语言和显示切换的实机结果来自 [2026-09-16 beta.1 验收](0.2.0-beta.1-validation.md)，不将其记为 beta.2 新执行的实机测试。2026-09-18 的共用后台工具另验证了帮助和状态按钮；按钮续问、完整新工具回归以及当前模型路径的压缩/后台子任务进度仍未完成实机验证。

本版通过 GitHub 分发。ClawHub 正式提交与服务端审核仍未进行；beta.1 的静态预检是历史记录，当前发布检查结果以本版附件为准。安装与升级见 [安装指南](../installation.md)。
