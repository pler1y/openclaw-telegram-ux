## 问题复测

1. 初轮 UX02/03/07 出现状态消息连接异常，原生回复正常。独立 Undici 连接配置及确定未发送的连接失败有限重试已完成；三项实机复测全部通过。未知提交结果仍不盲目重发。
2. 初轮 UX13 附件已送达，但该路径未产生 message_sent，状态未结束。明确成功 lifecycle end 后增加 5–10 秒收尾；真实复测确认文件送达并删除自有气泡。状态清理本身不被当作附件送达凭证。
3. 补充仅显示“补充已收到”。实机答案遵循了新要求，但没有足够事件证据为所有补充显示“已采纳”。
