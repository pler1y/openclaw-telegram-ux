## 脱敏证据与统计

统计窗口为 2026-09-16 12:18–13:02 UTC，覆盖核心与增强任务共 28 次运行：

- 28 次收到、28 次成功创建自有气泡、28 次绑定 run、28 次完成事件。
- 24 次成功收尾并删除自有气泡；4 次按测试要求取消并保留停止说明。
- 25 次工具开始与 25 次工具结束，5 次具体进度，1 次补充收件。
- 状态传输错误 0；回执延迟中位数 807ms、最大 1065ms。
- 延迟从插件观察到入站事件算到 Bot API 创建成功，不是用户点击发送到看到消息的时间。
- 附件路径的一次宽限清理由界面另行确认文件已送达；清理本身不证明附件送达。

Release 的 enhanced-events.jsonl 保留时间、事件、阶段和代号化路由/消息/任务标识；不包含真实 ID、聊天正文或工具结果。详细私聊界面证据仅保留本地，不进入仓库与安装包。最终发布包另执行部署和普通消息烟测，记录在 deployment-verification.json。

## 明确的验证边界

1. 按钮权限、重复、过期、旧任务和重启失效、submitText 返回路径通过可控测试；尚不能宣称真实按钮续问验收通过。语言与显示切换可使用已实测命令。
2. 压缩、子任务接口确实存在，适配及状态机通过可控测试；当前 xAI 路径没有观测到相应公开事件，状态展示未验证。不能据此笼统认定 OpenClaw 不支持。
3. 停止按钮没有可靠的公开原子 run 条件，不开放；额外中文停止短句没有公开重写入口，不增加。
4. 当前路径无法证明补充已排队、开始处理或已采纳，因此只确认收件。
5. 模型失败、审批、超时、多会话并发、429、网络中断及崩溃遗留恢复主要来自可控测试；不作为真实 Telegram 覆盖。群组和其他模型未做实机验收。
6. 官方检查为静态默认模式；dry-run 不是服务端审核或 ClawHub 收录。正式发布者身份、命名空间及提交另行处理。
