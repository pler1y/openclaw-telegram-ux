# 与 Hermes Telegram UX 的逐项对照

对照 Hermes 主线 1.8.3-rc.1 的功能说明（已发布基线 1.8.2）。本插件是独立实现，兼容 OpenClaw 2026.9.1。Hermes 主线通过运行时包装内部入口补足能力；这里仅使用第三方公开 SDK 与 Telegram 官方 Bot API，没有核心改动或内部方法替换。

| 体验 | OpenClaw 0.2.0-beta.1 的实现与边界 | 验证 |
| --- | --- | --- |
| 即时回执 | 插件创建自有气泡，普通入站到达后立即排队发送 | 实机、自动化 |
| 同气泡阶段 | 公开 Agent stream 驱动思考、搜索、工具、整理阶段；并行工具按 ID 计数 | 实机、并行可控测试 |
| 具体工作说明 | 当前模型调用公开 tgux_progress；文本最长 160 字符，当前 run/工具调用与可信路由联合校验 | 实机共五次更新，含自然调用；迟到、伪造、重放可控测试 |
| 进度生成方式 | 不另开模型生成进度，不读取内部思考；模型不调用时使用真实阶段 | 实机主动调用与事件回退 |
| 简洁 / 详细 | 简洁显示阶段和补充收件；详细增加工作说明、后台数量、经过时间、长等待提示 | 自动化与命令菜单；详见验收报告 |
| 经过时间 / 长等待 | 15 秒为单位显示经过时间；30 秒无事件时如实提示；不是完成百分比 | 英文长等待实机、自动化 |
| 中英文 | 插件自己的回执、终态、错误、帮助、菜单及工具说明双语；默认中文 | 运行中切换、中英文进度与终态实机，文案回归 |
| 菜单与偏好 | /tgux 的状态、帮助、语言、显示方式；只保存本插件偏好 | 命令操作实机，按钮权限与过期可控测试 |
| 继续解释 / 简要总结 | 授权点击后由公开 submitText 回到原生入站；旧任务菜单失效 | 可控测试；实际点击范围见验收报告 |
| 运行中补充 | 插件确认“补充已收到”，原生 steer 处理补充 | 实机、自动化 |
| 排队 / 已采纳区分 | 当前路径没有验证到能证明这些语义的公开事件；不使用猜测文案 | 保留原生行为；不宣称已实现 |
| 原生停止 | /stop，以及整条消息“停止”“停下来”“暂停”；以明确取消事件收尾 | 实机范围见验收报告，整条匹配可控测试 |
| Hermes 额外停止短句 | “等一下”“等下”“等等”“停”未增加命令映射；缺少可靠原生重写入口 | 公开接口限制；按普通文字处理 |
| 停止按钮 | 未开放。submitText 没有原子 expectedRunId 约束，旧按钮可能影响新任务 | 接口类型证据、测试确保不生成停止回调 |
| 上下文压缩 | 观察公开 before/after_compaction，只更新可唯一关联的现有任务 | 状态重叠可控测试；当前模型触发情况见报告 |
| 后台子任务 | 公开 spawned/progress/ended，可靠关联后显示数量和结束情况 | 父子结束顺序可控测试；实机情况见报告 |
| Markdown、引用、长回复 | 保留原生答案交付，不加工最终 payload | 实机 100 行、代码块、链接与 Unicode |
| 附件收发 | 完全由 OpenClaw 处理；成功后清理插件气泡 | 实机输入、输出 |
| 答案后清理 | 文本优先等待发送确认；附件可能缺少发送确认，明确成功后等待 5–10 秒 | 实机与可控测试；气泡删除不是独立送达证明 |
| 失败、停止、重启 | 保留准确短说明，终态幂等；重启只收尾旧状态，不恢复旧任务 | 停止/升级实机；故障和竞态可控测试 |
| 审批 | 观察公开 approval stream；不代替原生审批操作 | 可控测试，未宣称真实审批验收 |
| 限频与传输异常 | 同聊天串行合并，菜单与进度共用限频等待；不确定创建不重发 | 正常实机；429、网络错误可控测试 |
| 多会话 / 群组 | 状态隔离有自动化；公开版本实际验收范围为配置白名单私聊 | 群组未开放；多会话未做实机验收 |
| Hermes 的文字合并和队列策略 | 不接管接收端或更改原生 steer/queue；沿用 OpenClaw | 保留原生 |
| 安装与维护 | 标准 manifest、注册工具/命令/交互、固定 SDK、npm-pack 安装；无需修改核心 | 隔离生命周期、官方静态校验、GitHub CI |

“实现了观察适配”不等于所有模型路径都触发事件。报告分别列出实机证据、模拟覆盖和缺少公开关联字段时的跳过行为。ClawHub 校验通过也不代表已被目录收录。
