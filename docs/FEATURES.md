# 功能矩阵

| 功能 | 实现 | 验证范围 |
| --- | --- | --- |
| 中文即时回执 | 白名单私聊普通入站创建一个自有状态气泡 | 实机与自动化 |
| 思考 / 搜索 / 工具 / 整理 | 公开 Agent stream；并行工具按调用 ID 计数 | 实机搜索、多工具；并行计数可控测试 |
| 更新合并与限频 | 同账号同聊天串行，默认间隔 1.5 秒 | 实机事件时间；429 可控测试 |
| 补充消息 | 显示“补充已收到”；重复入站去重 | 正式模式运行中补充与可控测试通过 |
| 明确采纳提示 | 当前不显示“已采纳” | 目标路径没有验证到明确采纳事件 |
| 原生 steer / stop | 仅观察，不拦截或重写请求 | 正式模式工具中停止、临近完成停止、停止后请求通过 |
| 成功收尾 | 文本发送确认优先；成功任务缺少发送确认时等待 5–10 秒清理 | 普通回复、长文本及附件收尾实机通过 |
| 失败 / 取消 | 终态锁定，保留简短说明 | 取消实机；模型失败、配送失败可控测试 |
| 原生 Markdown / 引用 / 附件 | 不修改原生 payload 或附件路径 | 代码块目视检查；长文本、链接、附件实机 |
| 禁用 / 重启 | 停止观察新任务，已有状态收尾；重启不恢复旧 run | 实机部署重启、孤儿状态可控测试 |
| 不确定发送 | 不重发；已知连接前失败与 429 有限重试 | 实机连接异常与回归；其他超时可控测试 |
| 消息被删除 | 停止对失效消息的更新，不新建替代气泡 | 可控测试 |
| `/tgux` | 已授权目标私聊查看功能和运行状态 | 实机 |
| 多会话隔离 | account/chat/topic/session/run 联合约束，歧义跳过 | 可控测试；没有宣称多会话实机验收 |
| 审批提示 | 识别公开 approval stream 的已知 phase | 可控状态事件；无真实审批验收 |
| 按钮 / 完整双语 | 后续版本范围 | 未实现 |
