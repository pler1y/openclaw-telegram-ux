# 兼容性与验证范围

[文档首页](README.md) · [版本验证记录](releases/0.2.0-beta.1-validation.md)

## 支持矩阵

| 项目 | 当前范围 |
| --- | --- |
| OpenClaw | 精确版本 **2026.9.1**；其他版本拒绝注册 |
| Node.js | **≥ 24.16.0** |
| Telegram | 现有机器人、配置白名单中的已授权私聊 |
| 实机模型 | `xai/grok-4.6`；插件不替换模型 |
| 实机会话 | 单个默认 Telegram 账号的一个私聊 |
| 命名账号、并发隔离 | 有可控测试，尚未扩大实机验收 |
| 群组、话题 | 当前产品范围未开放 |
| 答案与附件 | 由 OpenClaw 原生交付 |

插件依赖、兼容元数据和运行时检查固定为同一宿主版本。`minHostVersion` 只是安装门槛，不表示后续 OpenClaw 版本自动兼容。

## 已实测的体验

即时回执、同气泡阶段更新、具体工作说明、语言与显示切换、经过时间与等待提示、补充收件、原生中英文停止、长文本与附件交付均有真实私聊记录。

原有 20 个核心场景在 0.2.0-beta.1 上重新执行；测试与模型路径的详细范围见版本报告。

## Beta 功能与限制

| 功能 | 当前结论 |
| --- | --- |
| 菜单按钮、继续解释、简要总结 | 显示和文字设置已实测；真实按钮回调与续问待补验 |
| 上下文压缩展示 | 公开适配和可控测试已实现；已测模型路径没有观察到相关 hooks |
| 后台任务数量与收尾展示 | 公开适配和父子顺序测试已实现；已测路径没有观察到相关 hooks |
| 补充“已采纳”等更强提示 | 当前公开事件不足以证明，只确认收到 |
| 停止按钮 | 不提供；公开提交入口缺少可原子约束当前 run 的停止语义 |
| 额外停止短句 | 仅沿用宿主已有短句，不增加原生命令映射 |
| 模型失败、审批、限频、崩溃恢复 | 主要为可控测试覆盖，不宣称全场景实机验证 |

没有明确任务关联时跳过事件，不把其他任务的状态套到当前气泡。具体工作说明是否出现，由模型是否调用公开工具决定。

## 维护与升级

SDK 仍会变化。增加兼容版本前需更新依赖、检查公开接口契约、跑隔离安装和回滚，再完成真实私聊验证。仅修改版本范围不足以声明支持。

当前基线 `v0.1.0-beta.1` 保留为回滚版本。重启只收尾遗留消息，不恢复旧任务；传输问题和处理方式见[问题排查](troubleshooting.md)。

接口依据见[公开接口文档](development/public-api.md)；与 Hermes 的体验差异见[逐项对照](hermes-comparison.md)。
